      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">Contrôles de base et mécanismes fondamentaux</h3>
        <div className="text-primary-foreground">
Le cœur de **Klondike Solitaire** réside dans ses mécanismes de base. Votre objectif ? Organiser toutes les cartes dans les tas de fondation. Costume par costume. As jusqu'au Roi. Les commandes sont généralement faites par glisser-déposer. Un clic révèle les cartes cachées.
          <br/>
          Partie principale :
          <ul>
            <li>Empilage : Construire les colonnes du tableau (les sept colonnes) en alternant les couleurs (rouge et noire) et en ordre décroissant.</li>
            <li>Révéler le jeu : Tirez des cartes du tas de pioche (le jeu principal) pour trouver vos prochains mouvements.</li>
            <li>La fondation : Déplacer les cartes du tableau vers la fondation, en commençant par les As.</li>
          </ul>
</div>
      </div>
      
      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">Éléments uniques de jeu</h3>
        <div className="text-primary-foreground">
Cette version de **Klondike Solitaire** propose des ajouts captivants.
          <ul>
            <li>Système d'indices : Bloqué ? Un système d'indices propose des suggestions stratégiques.</li>
            <li>Annuler les coups : Annulez un coup qui vous fait dévier du bon chemin.</li>
          </ul>
</div>
      </div>
      
      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">Avantage stratégique</h3>

          <ul>

            <li>Privilégiez les colonnes du tableau : Les colonnes vides offrent des avantages stratégiques.</li>
            <li>Utilisez les indices (parfois) : Ils peuvent éclairer les solutions.</li>
