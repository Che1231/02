      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">Controlli di base e meccaniche di base</h3>
        <div className="text-primary-foreground">
Il cuore di **Klondike Solitaire** risiede nelle sue meccaniche di base. L'obiettivo? Disporre tutte le carte nei mazzi di fondazione. Seme per seme. Asso fino al Re. I controlli sono solitamente basati su trascinamento e rilascio. Cliccando si rivelano le carte nascoste.
          <br/>
          Gioco di base:
          <ul>
            <li>Accatastamento: Costruisci le colonne di tableau (le sette colonne) con colori alternati (rosso e nero) e ordine decrescente.</li>
            <li>Rivelazione del mazzo: Prendi le carte dal mazzo di scorte (il mazzo principale) per trovare i tuoi prossimi mosse.</li>
            <li>Fondazione: Sposta le carte dal tableau alla fondazione, iniziando dagli assi.</li>
          </ul>
</div>
      </div>
      
      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">Elementi unici del gioco</h3>
        <div className="text-primary-foreground">
Questa versione di **Klondike Solitaire** offre aggiunte accattivanti.
          <ul>
            <li>Sistema suggerimenti: Incagliato? Un sistema di suggerimenti offre suggerimenti strategici.</li>
            <li>Annulla mosse: Annulla se una mossa ti manda fuori corso.</li>
          </ul>
</div>
      </div>
      
      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">

          <ul>

            <li>Priorità alle colonne di tableau: le colonne vuote offrono vantaggi strategici.</li>
            <li>Utilizza suggerimenti (a volte): possono illuminare le soluzioni.</li>
