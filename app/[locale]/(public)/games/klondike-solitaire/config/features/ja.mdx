      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">基本操作とコアメカニズム</h3>
        <div className="text-primary-foreground">
**Klondike Solitaire** の核心は、そのコアメカニズムです。あなたの目標は？すべてのカードを山札に並べることです。スートごとに。エースからキングまで。操作は通常、ドラッグアンドドロップです。クリックすると、隠されたカードが表示されます。
          <br/>
          基本的な遊び方：
          <ul>
            <li>積み重ね：七つの列（表札列）を交互の色（赤と黒）と降順に構築します。</li>
            <li>デッキの表示：ストックの山積からカードを引いて、次の手を見つけてください。</li>
            <li>山札：表札から山札にカードを移動します。エースから始めます。</li>
          </ul>
</div>
      </div>
      
      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">ユニークなゲームプレイ要素</h3>
        <div className="text-primary-foreground">
このバージョンの**Klondike Solitaire** は、魅力的な追加機能を提供しています。
          <ul>
            <li>ヒントシステム：詰まりましたか？ヒントシステムが戦略的な提案を提供します。</li>
            <li>手戻し：手がかりが間違っていたら手戻しでやり直しができます。</li>
          </ul>
</div>
      </div>
      
      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">戦略的優位性</h3>
        <div className="text-primary-foreground">
Klondike の達人になるには、戦略的な認識が必要です。
          <ul>
            <li>先読み：いつでも数手先を読みましょう。</li>
            <li>表札列を優先する：空の列は戦略的な利点となります。</li>
            <li>ヒントを活用する（場合によっては）：解決策を示唆する可能性があります。</li>
          </ul>
