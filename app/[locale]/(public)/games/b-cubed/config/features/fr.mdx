      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">Contrôles de base</h3>
        <div className="text-primary-foreground">
PC : utilisez les touches WASD ou les flèches directionnelles pour déplacer l'ensemble de cubes. Q et E font pivoter les cubes individuellement. La barre d'espace active le Décalage Lié (un mécanisme unique).<br/>
          Mobile : faites glisser pour déplacer. Pincer pour faire pivoter les cubes individuellement. Appuyez pour activer le Décalage Lié.
</div>
      </div>

      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">Objectif du jeu</h3>
        <div className="text-primary-foreground">
Dirigez le cube central vers le point de destination désigné. Manipulez la structure. Surmontez les défis spatiaux. B-Cubed exige de la précision. Le succès réside dans la compréhension de la nature interconnectée des cubes.
</div>
      </div>

      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">Conseils pour les pros</h3>

Maîtrisez le Décalage Lié ! Comprenez ses subtilités. Visualisez la configuration finale avant de faire un mouvement. Utilisez le système d'aperçu fantôme pour planifier à l'avance.
