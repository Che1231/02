Here is a detailed introduction to Minesweeper:

### Basic Information
- **Origin**: The Minesweeper game originated from a game called "Cube" in 1973. Later, through several modifications, Tom Anderson developed the prototype of Minesweeper. In 1992, it was incorporated into the Windows 3.1 system and became a software for training users' mouse operation ability.

### Gameplay
- **Game Goal**: The goal of the game is to find all the mines in the square matrix within the specified time without stepping on any mines. The player wins if all safe squares are opened and all mines are flagged, and loses if a mine - containing square is opened.
- **Game Interface**: The game interface consists of a square matrix. Mines are randomly distributed in the squares. Each square may contain a mine or be empty. The number displayed on the opened safe square indicates the number of mines in the surrounding squares. If it is an empty square (i.e., 0), the surrounding squares will be automatically opened.
- **Operation Methods**: Left - click an unopened square to open it; right - click an unopened square to mark or unmark it as a mine; double - click (left and right buttons simultaneously) a number on an opened square. If the number of mines marked around the number is equal to the number itself, all the remaining unopened squares around the number will be opened.
- **Difficulty Levels**: Usually, there are multiple difficulty levels. The beginner level is generally an 8x8 or 9x9 board with 10 mines, the intermediate level is a 16x16 board with 40 mines, and the expert level is a 30x16 board with 99 mines. There is also a custom mode where players can set the board size and the number of mines according to their preferences.

### Game Strategies
- **Starting in the Center**: It is advisable to start by clicking a square in the center of the board. This is because starting from the corner may lead to a situation where there are fewer movable squares in the early stage of the game, making it more likely to get stuck.
- **Looking for Patterns**: There are some common patterns in the game. For example, in a "1 - 2 - 1" pattern, the squares between the "1"s are mines, and in a "1 - 2 - 2 - 1" pattern, the mines are next to the "2"s.
- **Using Logic Deduction**: Based on the numbers on the opened squares, infer the locations of the mines. For example, if a square with the number "1" has only one unopened adjacent square, then that square must be a mine.
