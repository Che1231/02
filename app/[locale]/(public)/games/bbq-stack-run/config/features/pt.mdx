## O que é o Bbq Stack Run?

<div className="flex flex-col md:flex-row items-center  gap-4 md:gap-8">
  <div className="w-full md:w-1/2 text-xl">
Bbq Stack Run é mais do que um jogo; é uma busca culinária envolvida numa experiência de corrida frenética. Dominar o Bbq Stack Run significa empilhar diferentes ingredientes como um chef profissional. Este jogo lança-o num mundo onde velocidade e precisão se encontram com a deliciosa arte de construir churrascos perfeitos. O objetivo principal: construir a obra-prima de churrasco mais alta e saborosa enquanto evita obstáculos e ultrapassa seus rivais. É um teste de reflexos, seleção estratégica de ingredientes. O Bbq Stack Run oferece uma experiência de jogo única.
