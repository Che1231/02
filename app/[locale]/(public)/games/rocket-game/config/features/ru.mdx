## Что такое Rocket Game?

<figure class="flex flex-col md:flex-row items-center gap-4 md:gap-8">
  <div class="w-full md:w-1/2 text-xl">
Rocket Game — это захватывающая аркадная гонка, в которой игроки пилотируют космические корабли по опасным ландшафтам. Отличается улучшенной графикой, плавным управлением и множеством захватывающих испытаний.

  Когда игроки проносятся по живописным галактикам, Rocket Game обещает небывалый азарт, сочетая традиционный космический бой с современными элементами гонок.
