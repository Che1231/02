## Rocket Game 介紹

<figure class="flex flex-col md:flex-row items-center gap-4 md:gap-8">
  <div class="w-full md:w-1/2 text-xl">
Rocket Game 是一款令人振奮的街機賽車遊戲，玩家駕駛宇宙飛船穿梭於險峻的地形。擁有增強的圖形品質、流暢的操作機制和眾多的刺激挑戰。

當玩家在充滿活力的銀河系翱翔時，Rocket Game 將帶來無與倫比的興奮，融合了傳統太空戰鬥和現代賽車元素。
