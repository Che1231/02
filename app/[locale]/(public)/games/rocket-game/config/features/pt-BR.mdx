## O que é Rocket Game?

<figure class="flex flex-col md:flex-row items-center gap-4 md:gap-8">
  <div class="w-full md:w-1/2 text-xl">
Rocket Game é uma corrida arcade eletrizante onde os jogadores pilotam espaçonaves por terrenos perigosos. Apresenta fidelidade gráfica aprimorada, mecânicas de controle sem problemas e uma infinidade de desafios emocionantes.

À medida que os jogadores se elevam pelas galáxias vibrantes, Rocket Game promete emoção sem precedentes, combinando combate espacial tradicional com elementos modernos de corrida.

  <div class="w-full md:w-1/2">
    <div class="grid grid-cols-1 gap-2 md:gap-4 mt-0">
      <div class="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 class="text-primary font-bold mb-2">Controles Básicos</h3>
        <div class="text-primary-foreground">
PC: Use as teclas de seta ou WASD para controlar a espaçonave, a barra de espaço para aumentar a velocidade. <br/>
          Móvel: Deslize as áreas da tela para a esquerda/direita para controlar, toque no centro para ativar o aumento de velocidade.
</div>
      </div>

      <div class="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 class="text-primary font-bold mb-2">Objetivo do jogo</h3>
        <div class="text-primary-foreground">
Navegue por cada nível, colete power-ups e evite os oponentes para chegar ao ponto de chegada. (O objetivo final é vencer.)
</div>
      </div>

      <div class="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 class="text-primary font-bold mb-2">Dicas para Profissionais</h3>
        <div class="text-primary-foreground">
Utilize a agilidade da sua espaçonave para fazer curvas fechadas e posicione-se estrategicamente para obter uma vantagem de velocidade. (A agilidade refere-se à resposta e manobrabilidade da sua espaçonave)
</div>
      </div>
    </div>
  </div>
