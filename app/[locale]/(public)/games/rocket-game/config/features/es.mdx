## ¿Qué es Rocket Game?

<figure class="flex flex-col md:flex-row items-center gap-4 md:gap-8">
  <div class="w-full md:w-1/2 text-xl">
Rocket Game es una emocionante carrera arcade donde los jugadores pilotan naves espaciales por terrenos peligrosos. Presenta gráficos mejorados, controles sin problemas y una gran cantidad de emocionantes desafíos.

Mientras los jugadores se elevan por galaxias vibrantes, Rocket Game promete una emoción sin igual, combinando el combate espacial tradicional con elementos modernos de carreras.

## ¿Cómo jugar a Rocket Game?

<figure class="flex flex-col md:flex-row items-center gap-4 md:gap-8">
  <div class="w-full md:w-1/2">
<img 
      src="https://images.1games.io/cache/game/rocket-game/rocket-game2-m200x130.webp" 
      alt="Jugabilidad de Rocket Game" 
      class="w-4/5 h-auto mx-auto"
    />
</div>
  <div class="w-full md:w-1/2">
    <div class="grid grid-cols-1 gap-2 md:gap-4 mt-0">
      <div class="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 class="text-primary font-bold mb-2">Controles básicos</h3>
        <div class="text-primary-foreground">
PC: Utiliza las flechas del teclado o las teclas WASD para dirigir la nave espacial, la barra espaciadora para el impulso. <br/>
          Móvil: Desliza la pantalla izquierda/derecha para dirigir, toca el centro para activar el impulso.
</div>
      </div>

      <div class="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 class="text-primary font-bold mb-2">Objetivo del juego</h3>
        <div class="text-primary-foreground">
Navega por cada nivel, recoge potenciadores y supera a los oponentes para llegar a la meta. (El objetivo final es la victoria)
</div>
      </div>

      <div class="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 class="text-primary font-bold mb-2">Consejos para expertos</h3>
        <div class="text-primary-foreground">
Utiliza la agilidad de tu nave espacial para realizar giros cerrados y sitúate estratégicamente para obtener una ventaja de velocidad. (La agilidad se refiere a la capacidad de respuesta y maniobrabilidad de tu nave espacial)
</div>
      </div>
    </div>
  </div>
</figure>
