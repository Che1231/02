        <h3 className="text-primary font-bold mb-2">Controles básicos</h3>
        <div className="text-primary-foreground">
PC: Utiliza las teclas de flecha o WASD para moverte (navegación con el teclado estándar), barra espaciadora para saltar (impulsar la pelota hacia arriba). <br/>
Móvil: Toca las zonas izquierda/derecha de la pantalla (movimiento horizontal) para moverte, toca el centro (activar movimiento vertical) para saltar.
</div>
      </div>

      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">

Recoge todas las monedas (dispersas por los niveles) en cada nivel, evitando los obstáculos (trampas, enemigos) para llegar a la línea de meta (final del nivel).
</div>
      </div>

      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">Consejos para expertos</h3>

Aprovecha al máximo la capacidad de salto doble (extender los saltos) y planifica tu ruta con cuidado (estrategiza las rutas para la máxima eficiencia) para lograr puntuaciones altas.
