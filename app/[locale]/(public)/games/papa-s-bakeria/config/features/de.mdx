## Hauptmerkmale von Papa's Bakeria?

<div className="grid grid-cols-1 md:grid-cols-2 gap-2 md:gap-4">
  <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
    <h3 className="text-primary font-bold mb-2">Funktion: Bestellnahme</h3>
    <div className="text-primary-foreground">
Hier beginnt alles. Hören Sie genau zu. Notieren Sie sich alles. Ein zufriedener Kunde beginnt mit einer korrekten Bestellung in Papa's Bakeria.
      <br/>
      Operation: Klicken Sie auf die Kunden. Überprüfen Sie ihre Bestellungen. Bestätigen Sie die Richtigkeit.
      <br/>
      Strategie: Antizipieren Sie die Stoßzeiten. Bereiten Sie häufig benötigte Zutaten vor. So sind Sie bereit, die Dienstleistungen zu beschleunigen. Maximieren Sie das Trinkgeldempfangspotenzial!
</div>
  </div>

  <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
    <h3 className="text-primary font-bold mb-2">Funktion: Kruste herstellen</h3>
    <div className="text-primary-foreground">
Das Wälzen und Formen des Teigs klingt einfach. Aber es ist eine Kunstform, besonders in Papa's Bakeria.
      <br/>
      Operation: Wählen Sie die Teigart. Wälzen Sie ihn aus. Schneiden Sie die Ränder ab. Erreichen Sie eine gleichmäßige Dicke, während Sie die Kruste herstellen.
      <br/>
      Strategie: Aktualisieren Sie Ihre Teigwälzstation (ein in-game Upgrade). Dies beschleunigt diesen Prozess erheblich. Streben Sie auch Perfektion an. Eine makellose Kruste verhindert das Reißen beim Backen, während Sie die Perfektion in Papa's Bakeria anstreben.
</div>
  </div>

  <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
    <h3 className="text-primary font-bold mb-2">Funktion: Backen der Perfektion</h3>
    <div className="text-primary-foreground">
Der Ofen wartet. Das Backen ist der Ort, wo die Magie geschieht. Passen Sie die Zeit genau an. Brennen Sie das Meisterwerk nicht an. Stellen Sie sicher, dass Kunden wieder für mehr Papa's Bakeria-Genuss zurückkehren.
      <br/>
      Operation: Stellen Sie die Backzeit ein. Überwachen Sie die Torte. Nehmen Sie sie zum optimalen Zeitpunkt heraus.
      <br/>
        > Ein Spieler teilt seine Erfahrung: "Ich habe einmal ein Dutzend Torten verbrannt, weil ein echter Telefonanruf meine Papa's Bakeria-Sitzung unterbrochen hat. Die Kunden waren wütend! Jetzt schalte ich mein Telefon auf lautlos."
      Strategie: Investieren Sie in Ofenerweiterungen, die Sie benachrichtigen, wenn es fertig ist. Dies verhindert ein Überbacken. Optimieren Sie die Backpräzision, während Sie Ihr Gebäckreich in Papa's Bakeria aufbauen!
