  <div className="w-full md:w-1/2">
    <div className="grid grid-cols-1 gap-2 md:gap-4 mt-0">
      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">Controles básicos</h3>
        <div className="text-primary-foreground">
PC: Usa las teclas de flecha o WASD para mover los blobs arriba y abajo, barra espaciadora para saltar.<br/>
          Móvil: Desliza hacia la izquierda/derecha para mover, toca la parte inferior de la pantalla para saltar.
</div>
      </div>

      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">Objetivo del juego</h3>
        <div className="text-primary-foreground">
Combina las notas musicales de la pantalla guiando a los blobs a las posiciones correctas manteniendo el tempo. Evita perder notas o energía para avanzar de nivel.
</div>
      </div>

      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">Consejos para profesionales</h3>
        <div className="text-primary-foreground">
Utiliza las habilidades especiales del blob, como el escudo (desvía las notas malas) y la explosión (elimina los obstáculos). Practica con diferentes instrumentos y aprende sus ritmos distintivos para un mejor rendimiento.
</div>
      </div>
    </div>
  </div>
</div>
