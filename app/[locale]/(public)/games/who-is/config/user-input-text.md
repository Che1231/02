游戏《Who Is》通常指的是《Who Is It?》，是一款经典的儿童桌游，由Pressman Toys出版，适合6岁及以上的玩家，游戏人数为2人。以下是其详细介绍：
- **游戏准备**：游戏包含2个游戏控制台、48张控制台卡片、48张选择卡片。每位玩家选择一个游戏控制台，并随机抽取一张选择卡片，将其秘密地放入自己的控制台中，卡片上的人物即为该玩家需要猜测的对象。
- **游戏玩法**：游戏开始后，玩家通过轮流提问来猜出对方控制台中的人物。问题必须是可以用“是”或“不是”回答的，例如“是不是黄色头发？”“是否戴眼镜？”等。玩家根据对方的回答，将自己游戏控制台上不符合条件的人物卡片关闭。
- **游戏目标**：通过不断提问和排除，当某位玩家的游戏控制台上只剩下一个人物时，他可以大声喊出这个人物的名字。如果与对方控制台中的人物对应，则该玩家得分，并开始下一轮游戏。最先猜对五位人物的玩家获胜。

《Who Is It?》能训练玩家的观察力、注意力、表达力和逻辑推理能力，同时也是亲子间或朋友间互动的良好选择。
