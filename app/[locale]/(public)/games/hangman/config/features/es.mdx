## ¿Qué es Ahorcado?

<div class="flex flex-col md:flex-row items-center  gap-4 md:gap-8">
  <div class="w-full md:w-1/2 text-xl">
**Ahorcado** es un juego de adivinanza de palabras clásico con un toque moderno. Mantiene la mecánica central de juego intacta, pero añade nuevas características que lo hacen más emocionante que nunca. Con mejores gráficos, un nivel de dificultad ajustable y algunas divertidas variaciones al concepto original, esta versión de Ahorcado es perfecta tanto para jugadores nuevos como para profesionales experimentados.

    No se trata solo de adivinar palabras; se trata de usar tu ingenio, paciencia y estrategia. ¿Podrás salvar el día o la horca ganará?
</div>

Adivina letras para descubrir una palabra oculta. Cada fallo acerca al ahorcado a su final, así que piensa con cuidado. ¿Necesitas ayuda? Los **Potenciadores**, como pistas o revelaciones de letras, pueden darte la ventaja.

        <h3 class="text-primary font-bold mb-2">IA Adaptativa</h3>

        <div class="text-primary-foreground">
El juego se adapta a tu nivel de habilidad. Los nuevos jugadores se enfrentarán a **palabras más fáciles**, mientras que los experimentados se verán desafiados con obstáculos más difíciles como límites de tiempo o letras desordenadas.
</div>
      </div>

      <div class="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 class="text-primary font-bold mb-2">Consejos para Profesionales</h3>

        <div class="text-primary-foreground">
Empieza con las vocales más comunes (E, A, I) y consonantes (S, T, N). Guarda tus **Potenciadores** para esos momentos difíciles para sacar el máximo provecho de ellos.
</div>
