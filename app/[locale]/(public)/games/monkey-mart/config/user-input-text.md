Monkey Mart是一款由Tiny Dobbins开发的模拟经营类游戏。以下是其相关介绍：
- **游戏玩法**：玩家扮演一只负责管理超市的猴子。需要种植水果、收获农产品，并将各种食品摆放在摊位上出售，如香蕉、玉米、鸡蛋、花生等。顾客会挑选商品并在收银台等待，玩家站在收银机旁即可收款。随着游戏进展，玩家可以解锁新的通道、拓展市场、聘请助理帮忙，还能购买设备来制作如巧克力棒、咖啡、酸奶等高级产品。同时，要升级角色的管理技能、解锁新工作站并培训员工。
- **操作方式**：使用键盘上的WASD键或方向键控制猴子移动。站在空地上可种植作物，站在成熟的植物旁进行收获，将收获的食物放在摊位上出售。
- **游戏特色**：画面风格可爱，角色和场景设计吸引不同年龄段玩家。操作简单易懂，适合各类玩家。具有高度互动性，从与顾客交流到管理员工，都充满生活气息。玩家还能发挥创造力，按自己的风格布置商店，包括货架安排和产品选择。此外，游戏支持离线模式，玩家即使没有网络连接也能随时游戏。
