*Doodle Champion Island Games*是谷歌与日本动画工作室Studio 4℃合作开发的一款在线角色扮演浏览器游戏，于2021年7月发布，以庆祝2020年东京奥运会和残奥会，同时向日本民间传说和文化致敬。以下是其相关介绍：
- **游戏角色**：玩家控制一只名为Lucky的花斑猫在岛上冒险。Lucky来到冠军岛，这里汇聚了世界各地的人相互竞技。在游戏开始，Lucky要与两只狛犬进行一场乒乓球比赛来测试技能，之后她可以选择挑战岛上的七位冠军，分别擅长射箭、花样游泳、滑板、攀岩、乒乓球、橄榄球和马拉松等运动项目。
- **游戏玩法**：游戏世界中包含七个不同的区域，每个区域都有各自的特色和对应的冠军。玩家参与各种体育小游戏，通过赢得比赛获得神圣卷轴。玩家还可以加入由谷歌logo颜色分类的四支团队（红队乌鸦、蓝队公牛、绿队河童、黄队狐狸）之一，通过参加小游戏为所在团队积累积分，在奥运会结束时积分最高的团队获胜。此外，游戏中还有许多支线任务，例如帮助岛上居民完成物品收集或交易等任务，完成支线任务可获得奖杯，部分支线任务还能解锁更难版本的小游戏。
- **游戏特色**：采用经典家用游戏机的16位像素画风，操作简单，使用方向键和空格键即可进行游戏。游戏中穿插着精致细腻的手绘风过场动画，由Studio 4℃设计，动画素材选取了来自日本47个县的文化资源。

该游戏在2021年9月6日被谷歌从首页移除，但仍可在谷歌涂鸦档案中游玩。
