## O que é Doodle Jumping?

Doodle Jumping é um jogo deceptivamente simples, mas viciamente viciante. Você, caro jogador, controla o Doodler, pulando cada vez mais para o céu. Plataformas aparecem, desaparecem e, às vezes, até *se movem*! Com controles intuitivos de inclinação e uma estética charmosa desenhada à mão, Doodle Jumping oferece diversão arcade em doses pequenas.
