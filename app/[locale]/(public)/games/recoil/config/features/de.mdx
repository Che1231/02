      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">Kernmechanik</h3>
        <div className="text-primary-foreground">
Denken Sie an **Recoil**. Denken Sie an unerbittliche Kämpfe. Sie werden wütende Wellen von Feinden konfrontieren, wobei jede Begegnung eine Prüfung von Können und Strategie ist.
          Die Kernmechanik des Spiels beruht auf der Waffenanpassung und der Kartenkenntnis. Die strategische Nutzung der Umweltzerstörung ist ebenfalls entscheidend.
</div>
      </div>

      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">Einzigartige Mechaniken</h3>
        <div className="text-primary-foreground">
Erstens die "Kinetische Kette" (Bonus auf den Schaden): das Treffen von Gegnern in unmittelbarer Nähe. Zweitens die "Schwungkraft" (im Bewegung bleiben, um einen Bonus zu erhalten). Ihre Nutzung wird den Spaß und die Bedeutung von **Recoil** verstärken.
</div>
      </div>

      <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
        <h3 className="text-primary font-bold mb-2">Innovative Systeme</h3>
        <div className="text-primary-foreground">
Das Spiel verwendet ein dynamisches "Waffenbau"-System (passende Waffen an die Charakter-Stats anpassen), das unglaubliche Unterschiede bei den Builds ermöglicht. Auf diese Weise bietet das **Recoil**-Universum den Spielern eine neue Möglichkeit, zu gedeihen.
</div>
      </div>
    </div>
  </div>
