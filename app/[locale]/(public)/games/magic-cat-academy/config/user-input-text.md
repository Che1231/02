*Magic Cat Academy*（魔法喵学院）是谷歌为万圣节特别设计的一款网页游戏，于2016年10月30日首次发布。以下是关于它的详细介绍：

### 游戏玩法
玩家通过点击和滑动鼠标在屏幕上画出特定符号来释放魔法，以击退靠近主角猫咪Momo的鬼魂。常见符号有横线、竖线、“V”型、倒“V”型等，特殊符号包括爱心、圆形、螺旋、沙漏等，分别具有恢复生命、制造护盾、击退鬼魂、减速敌人等功能。

### 游戏剧情
- **2016年版本**：玩家扮演魔法学校的魔法师Momo，他意外唤出一个幽灵，幽灵偷走魔法书并占领学校，Momo需在图书馆、食堂、教室、体育馆及屋顶5个关卡与幽灵和Boss战斗，最终夺回魔法书。
- **2020年版本**：幽灵首领Marshmallow坠入海洋，其鬼魂附身海洋生物，Momo在海底的5个关卡与它们战斗，还结识了水手猫Captain Sugar，最终再次打败Marshmallow。
- **2024年版本**：Marshmallow在太空获得紫色星星变得更强大，鬼魂扩散到大气层。Momo在地球大气层的5个圈层与鬼魂战斗，最后和Marshmallow合作打败被紫色星星影响的太阳。

### 游戏特色
- **美术风格**：采用卡通化角色设计和色彩鲜艳的背景，充满魔法气息和万圣节元素，如南瓜灯、黑猫等。
- **操作方式**：操作简单，易于上手，通过鼠标或触摸屏绘制符号，但随着关卡推进，难度逐渐增加，具有一定挑战性。
- **本地化**：针对不同国家和地区的文化差异进行调整，通过简单符号和直观操作，在全球范围内获得较高接受度。

该游戏由谷歌的4个设计团队创作，分别负责美术设计、策划、制作及音乐。角色Momo取材自谷歌涂鸦成员朱莉安娜·陈养的猫。
