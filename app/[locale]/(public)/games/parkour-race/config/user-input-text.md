Parkour Race是一款由Madbox推出的休闲街机跑酷类手游。以下是其相关介绍：
- **游戏玩法**：玩家控制角色在高楼间跑酷，只需滑动手指或使用键盘的左右键控制人物左右移动，让角色适时跳到助力区域，角色的跳跃、攀爬等动作会自动完成。玩家要躲避赛道上的障碍物，超越其他对手，率先冲过终点线。
- **游戏特色**：全3D游戏场景，采用简约的3D小人风格，画面逼真，动作效果流畅；玩法上有日常比赛、关卡冒险等多种模式，还融入了竞速、解谜等元素；提供丰富的个性化装扮，包括各种角色皮肤、动作烟雾、涂鸦以及饰品等，玩家可通过赢得比赛获取奖励来解锁；游戏操作简单，降低了跑酷游戏的操作难度，同时保留了动作的炫酷感，适合所有年龄段的玩家。
