Terraria is a fun and exciting 2D sandbox game focused on action like exploration, building, crafting, survival, combat and mining. Both single-player and multiplayer modes are available for Terraria. The 2D sprite-tile graphics in the game are reminiscent of the Super NES's 16-bit sprites. The exploration-adventure gameplay of Terraria is acclaimed for being classic and evocative of games like the Metroid series and Minecraft.The Detailed GameplayPlayers begin the game in a randomly created setting with basic tools and a non-player character (NPC) tutorial to help them get going and draw their attention to gameplay mechanics and growth. The universe of this adventure game is composed of a number of tile layers that players can interact with and modify. One can discover a number of resources, such as metal ores, while exploring caverns.
