Vectaria.io is a game similar to Minecraft, but fully multiplayer! Start your excursion with one of four characters: Martha, Oliver, Mike and Rose. From this point you can jump right into the game and start playing! There are three main game modes to choose from: PvP (player vs player) an endurance map where you have to keep the different players in check and be stronger, another endurance mode but you can turn PvP on and off, making it a bit more relaxed but intriguing, finally an inventive mode where you can let your creative mind roam free and construct anything you want! There are so many choices to choose from while playing Vectaria.io, where do you start?
