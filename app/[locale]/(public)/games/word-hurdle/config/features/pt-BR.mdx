### Principais recursos do Word Hurdle?

  <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
    <h3 className="text-primary font-bold mb-2">O Dilema Diário</h3>
    <div className="text-primary-foreground">
Uma palavra, todos os dias. Este desafio inovador te mantém voltando. A pressão é real. Você está motivado a melhorar suas habilidades. É uma corrida contra o tempo. Com cada tentativa, você adquire conhecimento valioso de palavras. **Word Hurdle** tem uma barreira de entrada baixa, mas oferece profundidades infinitas.
</div>
  </div>

  <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
    <h3 className="text-primary font-bold mb-2">Dicas Codificadas por Cores</h3>
    <div className="text-primary-foreground">
Verde, laranja ou cinza: as cores são suas amigas. O feedback de cor informa imediatamente se você está no caminho certo. Este sistema promove aprendizado rápido. É um sistema visual para palavras. É intuitivo. As dicas te guiam por cada quebra-cabeça. **Word Hurdle** usa a linguagem de cores para fácil acesso.
</div>
  </div>

  <div className="bg-gray-800 p-2 md:p-4 rounded-lg">
    <h3 className="text-primary font-bold mb-2">Pensamento Estratégico</h3>
    <div className="text-primary-foreground">
**Word Hurdle** é mais do que apenas adivinhar. É dedução estratégica. Exige colocação de palavras atenta. Use letras de alta frequência primeiro (aquelas frequentemente usadas em palavras). Procure vogais repetidas. Em seguida, tente letras que não são tão comuns (como "Z" e "Q").
</div>
