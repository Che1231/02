Run 3是一款太空主题的跑酷类游戏。以下是其相关介绍：

### 游戏玩法
玩家控制角色在复杂的太空隧道网络中穿梭，通过使用方向键来移动、跳跃和沿着墙壁奔跑，利用独特的重力改变机制，在不同表面上移动以改变重力方向，从而避开危险的空洞和障碍物，到达关卡终点。

### 游戏模式
- **探索模式**：包含100多个预设关卡，玩家完成关卡可解锁新区域和角色，还能通过星系地图查看自己的游戏进度。
- **无尽模式**：提供无限的随机生成关卡，难度会随着玩家的前进不断增加，玩家需尽可能长时间地生存以获得高分，并可与全球玩家竞争。
- **编辑模式**：玩家可以创建并分享自己的关卡。

### 角色设定
游戏中有多个具有特殊能力的独特角色可供解锁和使用，如跑步者具有平衡的速度和跳跃能力，适合新手；滑板手速度快但控制需要技巧；小孩体型小而敏捷，适合狭窄空间；蜥蜴可以粘附在墙壁上；兔子有着出色的跳跃能力；学生具备特殊的隧道绘制能力等。

### 游戏特色
- **独特的太空主题**：游戏场景设定在外太空的隧道中，结合了3D游戏画面与独特的卡通风格，给玩家带来独特的视觉体验。
- **丰富的游戏内容**：拥有多种游戏模式、众多可解锁角色以及大量的关卡，还会定期更新内容，具有较高的趣味性和 replayability。
- **简单易上手**：控制方式简单直观，适合所有玩家轻松上手，但随着游戏进程推进，难度逐渐增加，具有一定挑战性。
