> Imaginez ceci : vous foncez sur l'autoroute, une file de voitures vous bloquant le chemin. Avec un léger mouvement de poignet, vous déviez dans la voie opposée, vous faufilant entre les véhicules. L'excitation du danger vous envahit tandis que vous ramassez des pièces, votre cœur battant au rythme du moteur de votre moto. C'est Traffic Rider — où chaque seconde compte et chaque course est une nouvelle aventure.
